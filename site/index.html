Five agents.
One type checker.

Strata runs several coding agents on one TypeScript repo at once. Each agent gets its own git worktree, and the expensive parts are shared: one type checker for all of them, dependencies cloned in seconds, and dev servers that clean up after themselves.

How it works, and where the name comes from. The type checker holds the project once, as a base. Each agent is a thin layer on top that holds only the files it changed.

Install

brew install c01-dev/tap/strata npm install -g stratagents curl -LsSf https://strata.c01.dev/install.sh | sh

Pre-release. These commands work once v0.1 is published. macOS (Apple silicon) and Linux.

What the agents share.

One type checker

A single tsgo (TypeScript 7.1) holds the base program, and each agent's changes are layered on top. Agents ask it over MCP for diagnostics, hover, definition, references and symbols.

With five agents that each check the files they edit, it uses 61 to 65% less memory than one checker per worktree. When all five check the whole project at the same moment, the saving is 21 to 30%.

Dependencies by clone

strata new clones node_modules from a worktree with the same lockfile, instead of installing again.

On cal.com, a new worktree with 3.3 GB of dependencies is ready in 5 to 8 seconds, or under one second from the warm pool. The install it replaces took 309 seconds.

Dev servers

Each agent's server gets its own port and a URL such as fix-login.app.localhost, hot reload included.

strata rm stops everything the agent started and frees its port.

Every agent, from the menu bar.

The macOS menu bar app shows each agent's state, memory, port and dev server, and the shared checker. Start or stop a dev server, open a worktree in Terminal, or remove an agent. It asks twice before discarding uncommitted work.

Prefer the terminal? strata status --watch shows the same, live.

Three commands to start.

  1. Set up the repo

    Writes strata.toml, starts the background service and creates the shared base.

    strata init

  2. Give an agent a worktree

    Its own branch, its dependencies and a port. Prints the path.

    cd "$(strata new fix-login)"

  3. Connect the agent

    For Claude Code, add this to the repo's .mcp.json.

    { "mcpServers": { "strata": { "command": "strata", "args": ["mcp"] } } }

Recipes for Claude Code, Codex, Cursor and Conductor are in the docs. Needs git 2.36, Node 20 and, for the shared checker, TypeScript 7.1 in the repo.
