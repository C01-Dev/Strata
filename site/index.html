Every agent, from the menu bar.

State, memory, port and dev server for each agent. Start, stop, open or remove in one click.

Download for macOS, or brew install --cask c01-dev/tap/strata-menubar. Signed and notarized.

Start in three commands.

  1. Set up the repo
    strata init
  2. Give an agent a worktree
    strata new fix-login
  3. Connect the agent (MCP)
    strata mcp
